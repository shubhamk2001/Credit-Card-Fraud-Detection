# Credit Card Fraud Detection

A machine-learning project for identifying potentially fraudulent credit-card transactions.

## Contents

| File | Description |
| --- | --- |
| `Credit Card Fraud Detection.ipynb` | Notebook for data preparation, model training, and evaluation. |

## Dataset

The notebook uses the public [credit-card fraud dataset on Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud/data). Download the dataset and configure its path before running the notebook.

## Workflow

1. Load and explore transaction data.
2. Address class imbalance.
3. Train classification models.
4. Evaluate precision, recall, F1 score, and the confusion matrix.

## Disclaimer

This is an educational project, not a production fraud-detection system.
